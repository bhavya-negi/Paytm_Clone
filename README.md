# Paytm Clone 💸

A full-stack digital wallet and payment application inspired by Paytm. This platform allows users to securely sign up, view their wallet balance, and transfer funds to other registered users in real-time.

## 🚀 Features
* **Secure Authentication:** User signup and login with JWT-based authentication and password hashing.
* **Wallet Dashboard:** Real-time display of user account balances.
* **Money Transfers:** Secure peer-to-peer money transfers utilizing database transactions to ensure atomic operations (preventing partial failures).
* **User Search:** Search for other users on the platform to quickly send money.
* **Responsive UI:** Clean, mobile-friendly interface built with utility-first CSS.

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (with Mongoose for schema modeling)
* **Security:** JWT for Auth, bcrypt for hashing
